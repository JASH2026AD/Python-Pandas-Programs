# 🐼 Python Pandas Programs

A collection of Python programs created to practice and understand the **Pandas library** for data analysis and manipulation.

This repository contains beginner-friendly examples demonstrating different Pandas operations using Python.

## 📌 Topics Covered

- Introduction to Pandas
- Creating Series and DataFrames
- Reading CSV files
- Displaying dataset information
- Selecting rows and columns
- Filtering data
- Sorting data
- Handling data using Pandas
- Basic data analysis operations


## 🛠️ Technologies Used

- Python
- Pandas
- CSV
- VS Code

## 📦 Installation

Make sure Python is installed on your system.

Install Pandas using:

pip install pandas

## ▶️ How to Run

Clone the repository:

git clone https://github.com/JASH2026AD/Python-Pandas-Programs.git

Move into the project directory:

cd Python-Pandas-Programs

Run any program:

python p1.py

The purpose of this repository is to practice **Python Pandas concepts** and improve data analysis and data manipulation skills through simple programs.
